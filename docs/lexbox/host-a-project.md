A project on Lexbox gives your team one shared home for its data: everyone
Sends/Receives against it, and you manage the member list on the website.

## Ask for a project

On **My Projects**, choose **Create Project** (you need a verified email address to see
it). The form asks for:

- **Name** — usually the name of the language you are working on.
- **Project type** — FieldWorks, WeSay (LIFT), OneStory Editor, OurWord or Adapt It.
- **Purpose** — a real **Language Project**, or **Training**/**Testing** for practice
  projects.
- **Language Code** — preferably the [Ethnologue code](https://www.ethnologue.com/) of
  the language.
- **Description**, and whether the project is **confidential** (see
  [Members and roles](/lexbox/manage-members#confidential-projects)).

Lexbox builds the project code from your answers — for example `abc-flex` for a
FieldWorks project on language `abc`. If similar projects already exist, the form shows
them and offers **Ask to join** instead, so teams don't split their work by accident.

## Approval

If you already manage a project on Lexbox, the button reads **Create Project** and the
project is created right away. Otherwise it reads **Request Project**: the project shows
up under My Projects marked **Awaiting approval**, an administrator reviews the request,
and you get an email when it is approved.

## Fill it with data

A new project starts empty. Put your data in with your program's first Send/Receive —
in FieldWorks that is **Send/Receive** → **Send this Project for the first time**. The
project's page on lexbox.org shows these steps under **Set up project**, with your login
and project code already filled in. See [Send/Receive](/lexbox/send-receive/).
